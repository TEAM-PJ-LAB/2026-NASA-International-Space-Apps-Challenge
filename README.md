# LunarSafe

NASA Space Apps Challenge 2026 — Lunar Landing Site Navigator 출품 프로젝트 (Team PJ).

달 남극 두 후보지에서, 사용자가 정한 임무 조건을 만족하는 시작 시점을 찾고 그 판단이 지형 불확실성 아래에서도 유지되는지 보여주는 웹 애플리케이션.

- 제품 요구사항: [docs/PRD.md](docs/PRD.md)

## 상태

기획 단계. 대회 규정상 **코드 작성은 2026-11-14 09:00(현지 시간) 이후에 시작한다.** 그 전에는 이 저장소에 문서만 둔다.

Research and educational prototype. Not a flight-certified mission planning tool.
